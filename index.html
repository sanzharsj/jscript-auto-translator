📖 JScript Auto-Translator 사용 가이드
처음 사용하시는 분을 위한 3단계 안내
STEP 1 / 3
API Key 발급받기
Google Gemini를 예시로 안내합니다 (무료 사용 가능)
1
Google AI Studio 접속
웹 브라우저에서 aistudio.google.com/app/apikey 로 이동합니다. Google 계정으로 로그인이 필요합니다.
2
"Create API key" 클릭
화면 우측 상단의 Create API key 버튼을 클릭합니다. 새 프로젝트를 만들거나 기존 프로젝트를 선택할 수 있습니다.
3
API Key 복사
생성된 키 (예: AIzaSy...로 시작하는 문자열)를 클립보드에 복사합니다. 이 키는 비밀번호처럼 외부에 공개하지 마세요.
💡 참고: Gemini는 무료 한도가 넉넉합니다. Claude, OpenAI도 동일한 방식으로 각 사이트에서 키를 발급받을 수 있습니다.
STEP 2 / 3
설정 탭에서 API Key 등록
발급받은 키를 안전하게 저장합니다
1
상단 "⚙ 설정" 탭 클릭
화면 상단의 ⚙ 설정 탭을 클릭해서 설정 화면으로 이동합니다.
2
번역 엔진 선택
사용할 AI 엔진(Gemini, Claude, OpenAI 중)을 선택합니다. 처음이라면 Gemini를 권장합니다.
3
API Key 입력 후 저장
Gemini 행의 입력란에 복사한 키를 붙여넣고 저장 버튼을 클릭합니다. 키는 브라우저에만 저장되며 외부로 전송되지 않습니다.
🔒 보안: API Key는 브라우저의 localStorage에만 저장됩니다. 공용 PC라면 작업 후 반드시 키를 삭제해 주세요.
STEP 3 / 3
번역 실행하기
CSV 파일 업로드부터 결과 다운로드까지
1
CSV 양식 다운로드
우측 상단의 ⬇ CSV 양식 다운로드 버튼을 눌러 양식을 받고, 한국어 자막을 입력해 저장합니다.
2
파일 업로드
"번역" 탭의 업로드 영역에 작성한 CSV 파일을 드래그하거나 클릭해서 업로드합니다. 미리보기로 데이터를 확인하세요.
3
번역 시작 → 결과 다운로드
번역 시작 버튼을 누르면 영어·러시아어·베트남어로 자동 번역됩니다. 완료 후 결과 CSV를 다운로드할 수 있습니다.
✨ 완료! 작업 이력은 좌측 사이드바에서 다시 다운로드할 수 있습니다. 문의 사항은 담당자에게 연락해 주세요.
